# Quote Generation Workflow Guide

This guide documents the complete quote generation workflow from brand origin acceptance to quote delivery.

## Overview

The quote generation workflow (`src/workers/quoteGeneration.js` and `src/services/quoteService.js`) handles:
1. Context assembly from project data
2. LLM-based quote item generation
3. ERP quote creation (main + 3 variants)
4. PDF generation and Google Drive upload
5. Database record creation
6. Email notifications

## Workflow Steps

### Step 1: Trigger Quote Generation

Quote generation is triggered when a Brand Origin document is accepted:

**Location**: `src/workers/emailIntent.js` → `handleBrandOriginAcceptance()`

```javascript
// Enqueue quote generation job
await QueueService.addQuoteGenerationJob({
  projectId: project.id,
  dedupeKey: `project:${project.id}:quote:generate`,
  correlationId
});
```

**Deduplication**: Uses dedupe key to prevent duplicate quote generation for the same project.

### Step 2: Context Assembly

**Location**: `src/services/quoteService.js` → `assembleQuoteContext()`

Assembles complete context for quote generation:

1. **Project Data**: Project details, client information
2. **Questionnaire Responses**: Latest processed questionnaire
3. **Brand Origin Document**: Accepted brand origin document content
4. **Rate Card**: Studio rate card from `global_configs` (key: `rate_card`)

**Rate Card Structure**:
- Stored in `global_configs` table
- Key: `rate_card`
- Structure: See `rateCard.json` for schema
- Contains service categories and pricing

### Step 3: LLM Quote Item Generation

**Location**: `src/services/quoteService.js` → `generateQuoteItemsWithLLM()`

**Process**:
1. Generate LLM context using `QuotePromptService.generateLLMContext()`
2. Get quote items schema (Zod schema for structured output)
3. Call LLM with structured output
4. Validate returned items array

**LLM Prompt Service**: `src/services/quotePromptService.js`
- `generateLLMContext()` - Assembles context for LLM
- `generateSystemPrompt()` - System prompt with rate card guidelines
- `generateQuotePrompt()` - User prompt with project requirements
- `generateQuoteItemsSchema()` - Zod schema for structured output

**Output Format**:
```javascript
{
  items: [
    {
      item_code: "WEB-DESIGN-BASIC",
      description: "Basic Website Design",
      qty: 1,
      rate: 500000
    },
    // ... more items
  ]
}
```

### Step 4: Customer Setup (CRITICAL)

**Location**: `src/services/quoteService.js` → `ensureCustomerExists()`

**Process**:
1. Search for customer by exact name using `erpIntegration.searchOrCreateCustomer()`
2. If exact match found: use existing customer `name` field
3. If no exact match: create new customer
4. Return customer name (primary key) for quote creation

**Why Critical**: Customer must exist before quote creation. Customer `name` field is the primary key used in quotes.

### Step 5: Item Setup (CRITICAL)

**Location**: `src/services/quoteService.js` → `ensureItemsExist()`

**Process**:
1. For each quote item generated by LLM:
   - Search for item by exact `item_code` or `item_name`
   - If exact match found: use existing item `item_code`
   - If no exact match: create new item
2. Return validated items array with confirmed item codes

**Why Critical**: All items must exist before quote creation. Missing items cause quote creation failures.

### Step 6: Create Quotes via ERP

**Location**: `src/services/quoteService.js` → `createQuotesViaERP()`

**Process**:
1. **Main Quote**: Create with base quote items
2. **Variant Quotes** (3 variants):
   - Generate variant-specific items using LLM
   - Ensure variant items exist in ERP
   - Create variant quote with different pricing/scope

**Quote Creation**:
- All quotes created in DRAFT status (docstatus: 0)
- Customer name and validated item codes used
- Transaction date: Today
- Valid till: 3 months from today

**Return Value**:
```javascript
{
  mainQuoteId: "SAL-QTN-2025-00001",
  variantIds: [
    "SAL-QTN-2025-00002",
    "SAL-QTN-2025-00003",
    "SAL-QTN-2025-00004"
  ]
}
```

### Step 7: Download PDFs

**Location**: `src/services/quoteService.js` → `downloadQuotePDFs()`

**Process**:
1. For each quote ID:
   - Verify quote is not cancelled using `getQuotation()`
   - Download PDF using `getQuotationPDF()`
   - Return PDF buffer with metadata

**Error Handling**: Continues with other PDFs if one fails.

### Step 8: Upload PDFs to Google Drive

**Location**: `src/services/quoteService.js` → `uploadQuotePDFsToDrive()`

**Process**:
1. Get or create documents folder
2. Upload each PDF to Drive
3. Return Drive file IDs and links

**File Naming**: `Quote_{quoteId}.pdf`

### Step 9: Create Database Records

**Location**: `src/workers/quoteGeneration.js` → `quoteGenerationProcessor()`

**Process**:
1. Create `Document` record:
   - Type: `DocumentType.QUOTE`
   - Status: `DocumentStatus.DRAFT`
   - `erpQuoteId`: Main quote ID
   - `erpVariantIds`: JSON array of variant IDs
   - `selectedQuoteId`: null (set when Finance Manager selects)
   - `driveFileId`: Main quote PDF Drive file ID

2. Create `DocumentRevision`:
   - Snapshot text: Quote items summary
   - Snapshot MD: Quote metadata (quote IDs, items, etc.)
   - Drive file ID: Main quote PDF

### Step 10: Asana Updates

**Location**: `src/workers/quoteGeneration.js`

**Process**:
1. Move task to "Quote Document Phase" section
2. Add comment tagging Finance Manager
3. Comment: "Quote document created. Please check your email to review and send to client."

### Step 11: Email Notification

**Location**: `src/services/emailTemplateService.js` → `generateQuoteNotificationTemplate()`

**Recipients**: Finance Manager & Admin

**Email Content**:
- View button: Opens Drive link to main quote PDF
- Send to Client buttons: One per quote variant (main + 3 variants)
- Manage button: Opens Admin UI
- List all 4 quote variants with IDs/links

**Quote Selection**: Finance Manager clicks "Send to Client" button for desired quote variant. This automatically selects that quote and sends it to the client.

## Quote Selection & Sending

### Quote Selection

**Location**: `src/routes/actions.js` → `POST /actions/send-to-client`

**Process**:
1. Extract selected quote ID from query parameter (`quoteId`)
2. Update `Document.selected_quote_id` with chosen quote ID
3. Use selected quote PDF for sending

**Email Template**: Includes "Send to Client" button for each variant with `quoteId` query parameter.

### Sending Quote to Client

**Location**: `src/services/documentSendingService.js` → `sendDocumentToClient()`

**Process**:
1. Verify `selected_quote_id` is set
2. Download selected quote PDF from ERP (if needed)
3. Upload to Drive (if not already uploaded)
4. Share Drive file with client (no notifications)
5. Send email to client with PDF attachment
6. Update `last_sent_revision_id` with quote info

## Quote Feedback Loop

### Intent Detection

**Location**: `src/workers/emailIntent.js` → `handleDocFeedbackIntent()`

**Process**:
1. Detect DOC_FEEDBACK intent on Quote document
2. Use `selected_quote_id` to know which quote client is referring to
3. Enqueue quote update job

### Quote Update

**Location**: `src/workers/quoteGeneration.js` → `updateQuoteProcessor()`

**Process**:
1. Get selected quote ID from document
2. Verify quote not cancelled using `getQuotation()`
3. **If cancelled**: Use `amendQuotation()` to create new draft (update `selected_quote_id` with new ID)
4. **If draft**: 
   - Identify new items in feedback
   - Ensure new items exist in ERP
   - Fetch existing items from quote
   - Modify items array based on feedback
   - Update quote with complete items array
5. Generate new PDF
6. Upload to Drive
7. Create new DocumentRevision
8. Update `last_sent_revision_id`

**Important**: Only update the selected quote, not all variants.

## Quote Acceptance

**Location**: `src/workers/emailIntent.js` → `handleQuoteAcceptance()`

**Process**:
1. Update document status to ACCEPTED
2. Submit quote via ERP: `submitQuotation(selected_quote_id)` (docstatus: 0 → 1)
3. Create invoice: `createSalesInvoice(selected_quote_id, invoiceData)`
4. Store invoice ID in document metadata JSON
5. Send confirmation email (if detected via email intent)
6. Finalize project

## Error Handling

### Retry Logic

- ERP API failures: Retry with exponential backoff (3 attempts)
- LLM failures: Retry with different model (fallback)
- Drive upload failures: Retry up to 3 times

### Partial Success Handling

- If variant creation fails: Continue with other variants
- If PDF download fails: Continue with other PDFs
- Log all failures for manual review

### Validation

- Verify customer exists before quote creation
- Verify all items exist before quote creation
- Verify quote not cancelled before operations
- Validate LLM output structure

## Database Schema

### Document Model

```prisma
model Document {
  id              Int      @id @default(autoincrement())
  type            String   // QUOTE
  status          String   // DRAFT, PM_REVIEW, FINANCE_MANAGER_REVIEW, SENT_TO_CLIENT, CLIENT_FEEDBACK, ACCEPTED
  erpQuoteId      String?  // Main quote ID
  erpVariantIds   Json?    // [variant1_id, variant2_id, variant3_id]
  selectedQuoteId String?  // Which quote was sent to client
  driveFileId     String?  // Main quote PDF Drive file ID
  metadataInfo    Json?    // { invoiceId: "INV-xxx" }
  // ... other fields
}
```

## Best Practices

1. **Always verify prerequisites**: Customer and items must exist before quote creation.

2. **Handle cancellation**: Always check quote cancellation status before operations.

3. **Complete items array**: When updating, send full items array, not partial.

4. **Track selected quote**: Use `selected_quote_id` to know which quote client is referring to.

5. **Error recovery**: Continue with other quotes/PDFs if one fails.

6. **Logging**: Log all operations for audit trail and debugging.

## Common Issues

1. **Customer not found**: Ensure customer search/create happens before quote creation.

2. **Item not found**: Ensure all items exist before quote creation/update.

3. **Cancelled quote**: Use `amendQuotation()` to create new draft from cancelled quote.

4. **Partial update**: Sending partial items array removes items not included.

5. **Wrong quote ID**: After amending, use new quote ID from `data.name`.
